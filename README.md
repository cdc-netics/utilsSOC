## Installation

Descargar NodeJS 
(https://nodejs.org/en/download/current)

Clonar este repositorio

```bash
  cd my-project
  npm init playwright@latest
```




## Running Tests

Para la ejecucion estar parado en la raiz del proyecto

```bash
  npx playwright test tests/<NOMBRE_SCRIPT>.spec.ts --headed --project=chromium
```
